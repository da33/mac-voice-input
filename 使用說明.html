它能做什麼

游標在哪，字就打在哪

LINE、Word、Notion、Google 文件、瀏覽器、Email 都能用。不用切換視窗，也不用複製貼上。

在自己的電腦上辨識

用 Mac 內建的蘋果語音辨識，聲音不會上傳到網路，沒有網路也能用。

聽錯的字教它一次

網路

Mac 內建的就可以，外接的也行

安裝

只要做一次，大約 3 分鐘。

  1. 下載、解壓縮，放到固定的地方

    先下載 mac-voice-input.zip，雙擊解壓縮，把解開的 語音輸入 資料夾放到「文件」之類的地方。之後不要再搬動，搬了要重新安裝一次。

  2. 執行安裝程式

    打開「終端機」（在「應用程式 → 工具程式」裡），打 zsh （zsh 後面有一個空格），再把資料夾裡的 安裝App.command 拖進終端機視窗，按 Enter。

    zsh

    它會自動下載 uv（免費的 Python 套件管理工具）、Python 和需要的套件，網路正常大約 1 分鐘。看到「✅ 完成！」就裝好了，資料夾裡會多出 語音輸入.app。

    請用拖的，不要直接雙擊「安裝App.command」：從網路下載的檔案直接雙擊，會被 macOS 擋下來。

  3. 打開語音輸入，開權限

    雙擊 語音輸入.app，桌面下方會出現小膠囊。再到「系統設定 → 隱私權與安全性」，把這兩個地方的「語音輸入」打開：

    • 輸入監控：偵測你按下 Fn
    • 輔助使用：自動把文字貼上（沒開的話文字只會複製，要自己按 ⌘V）

    第一次錄音時會問能不能用麥克風，按「允許」。第一次啟動也會自動向蘋果下載中文語言包（免費，只要一次）。

  4. 把 🌐 鍵原本的功能關掉

    Fn 鍵按一下原本會切換輸入法，會跟語音輸入衝突。到 系統設定 → 鍵盤 →「按下 🌐 鍵時」，改成 「不執行任何動作」。

    • 之後切換輸入法（ABC ↔ 注音）改用 Control + 空白鍵
    • 不想改的話，也可以把語音輸入的快捷鍵換成右 Option（點小膠囊 → 快捷鍵）

常見問題

跳出「要安裝命令列開發者工具嗎」的視窗

語音輸入用不到開發工具，按「取消」就好。

按 Fn 沒反應

到「系統設定 → 隱私權與安全性 → 輸入監控」，確認「語音輸入」有打開。

文字沒有貼上，只複製了

「輔助使用」沒打開。打開後就會自動貼上，不用重開。

按 Fn 跳出表情符號或切換輸入法

照安裝第 4 步，把「按下 🌐 鍵時」改成「不執行任何動作」。

辨識不準

通常是麥克風的問題，在選單「麥克風」換一支試試。常錯的英文詞加到「自動更正」。

同音的中文詞（例如「城市／程式」）不適合放自動更正，會把真的「城市」也改掉。講慢一點、離麥克風近一點，會準很多。

會不會把我的聲音傳到網路上？

不會。辨識全部在你自己的電腦上做，用的是 Mac 內建的蘋果語音辨識。只有第一次會向蘋果下載中文語言包，之後都不用網路。

Intel 的 Mac、macOS 15 可以用嗎？

不行。蘋果的這個語音辨識是 macOS 26 才有的；安裝程式也只附了 Apple 晶片的版本。安裝程式一開始會先檢查，不符合會直接告訴你原因，不會亂裝東西。

麥克風卡住、程式閃退怎麼辦？

會自動重新啟動，小膠囊會顯示「麥克風恢復了」或「剛剛閃退了，已經自動重新打開」。等 1～2 秒再按一次 Fn 就好。

怎麼移除？

1. 點小膠囊，先取消「登入時自動啟動」，再按「結束語音輸入」。

2. 把整個「語音輸入」資料夾丟到垃圾桶。

3. 在「系統設定 → 隱私權與安全性」的「輸入監控」和「輔助使用」裡把「語音輸入」刪掉。

4. 安裝時自動下載的 uv 和 Python 在 ~/.local/bin/uv、~/.local/share/uv、~/.cache/uv，其他程式沒在用的話也可以刪掉。
