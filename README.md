# 語音輸入（Mac 版）

按住 **Fn** 鍵講話，放開後文字就直接出現在游標位置。LINE、Notion、Word、瀏覽器都能用。

- **免費、聲音不上傳**：用 Mac 內建的蘋果語音辨識，在你自己的電腦上辨識
- **快、輕**：放開按鍵後約 **0.2 秒**出字，只佔約 **50MB** 記憶體
- 常聽錯的詞可以設定「**自動更正**」，教一次之後就會改對

**👉 [下載 mac-voice-input.zip](https://github.com/da33/mac-voice-input/releases/latest/download/mac-voice-input.zip)**　｜　**[有圖的安裝說明](https://da33.github.io/mac-voice-input/)**

## 需要什麼（先確認你的 Mac 能不能用）

點螢幕左上角的蘋果圖示 →「**關於這台 Mac**」，看下面兩項。**兩項都要符合**才能用：

| 項目 | 需求 | 怎麼看 |
|---|---|---|
| 晶片 | **Apple 晶片**（M1、M2、M3、M4、M5） | 「晶片」寫 **Apple M…** 就可以；寫「處理器 Intel」的不能用 |
| 系統 | **macOS 26（Tahoe）以上** | 最上面寫 **macOS Tahoe 26.x** 就可以；15（Sequoia）以前的要先到「系統設定 → 一般 → 軟體更新」更新 |

其他：

| 項目 | 說明 |
|---|---|
| 空間 | 約 200MB（大部分是 Python 和套件） |
| 網路 | 只有**安裝**和**第一次打開**要連網路：安裝時下載 Python 和套件；第一次打開時向蘋果下載中文語音辨識的語言包（免費）。之後辨識不用網路 |
| 麥克風 | Mac 內建的就可以，外接的也行 |
| 語言 | 中文（台灣），夾雜的英文詞也聽得懂 |
| 不用 | 不用付費、不用註冊帳號，也不用安裝 Xcode 或開發工具 |
| 不支援 | **Windows、Intel 晶片的 Mac、macOS 15 以前** |

## 安裝（只要做一次，約 3 分鐘）

1. [下載 mac-voice-input.zip](https://github.com/da33/mac-voice-input/releases/latest/download/mac-voice-input.zip)，雙擊解壓縮，把 `語音輸入` 資料夾放到固定的地方（例如「文件」），之後不要再搬動
2. 打開「**終端機**」（在「應用程式 → 工具程式」裡），打 `zsh `（zsh 後面有一個空格），
   再把資料夾裡的 **`安裝App.command`** 拖進終端機視窗，按 Enter。
   它會先檢查你的 Mac 符不符合需求，再自動下載 uv（免費的 Python 套件管理工具）、Python 和需要的套件，網路正常大約 1 分鐘。
   看到「✅ 完成！」就裝好了，資料夾裡會多一個 `語音輸入.app`。
   （用拖的、不要直接雙擊 `安裝App.command`：從網路下載的檔案直接雙擊會被 macOS 擋下來）

## 第一次打開

1. 雙擊 **`語音輸入.app`**。桌面下方會出現一條小膠囊（浮動條），選單列會出現麥克風圖示
2. 到「系統設定 → 隱私權與安全性」，在這兩個地方把 **「語音輸入」** 打開：

   | 權限 | 用途 |
   |---|---|
   | **輸入監控** | 偵測你按下 Fn |
   | **輔助使用** | 自動把文字貼上（沒開的話文字會先複製，要自己按 ⌘V） |

   第一次錄音時還會問能不能用**麥克風**，按「允許」。
3. 把 🌐 Fn 鍵原本的功能關掉（每台 Mac 都要做）：**系統設定 → 鍵盤 →「按下 🌐 鍵時」→ 改成「不執行任何動作」**
   - 之後切換輸入法（ABC ↔ 注音）用 **Control + 空白鍵**
   - 不想改的話，也可以把語音輸入的快捷鍵換成右 Option 等其他鍵（點浮動條 → 快捷鍵）
4. 第一次啟動會自動向蘋果下載「中文（台灣）」語音辨識語言包（免費，只需要一次）
5. 想每次開機都自動啟動：點浮動條 → 勾「登入時自動啟動」

## 怎麼用

| 動作 | 結果 |
|---|---|
| **按住 Fn** 講話，講完放開 | 文字自動貼到游標位置 |
| **輕按一下 Fn** | 免持錄音（可以放開手講長一點），講完再按一下 Fn 或點浮動條就結束 |
| 免持錄音時按 **Esc** | 取消這次錄音 |
| 按住 Fn 時又按了別的鍵 | 當作你在用組合鍵，自動取消錄音 |

| 浮動條 | 意思 |
|---|---|
| 小小一條 | 待命中 |
| 紅點＋跳動的聲波 | 錄音中 |
| 右邊多一個小方塊 | 免持錄音中，點一下就結束 |
| 流動的波浪 | 辨識中 |

**拖曳**浮動條可以移到任何位置；**點一下**打開設定選單。

## 設定選單（點浮動條或選單列的麥克風圖示）

| 選項 | 說明 |
|---|---|
| 快捷鍵 | Fn、右 Option、右 Command… |
| 麥克風 | 選要用哪支麥克風 |
| 自動更正 | 每行一條「聽錯的字 → 正確的字」，例如 `Cloud Call → Claude Code` |
| 提示音 | 開始／結束錄音的聲音 |
| 平常也顯示浮動條 | 關掉的話，只有錄音時才會出現 |
| 登入時自動啟動 | 開機後自動在背景執行 |
| 複製上一段文字 | 剛剛貼錯地方的話，可以從這裡再拿一次 |
| 開啟歷史紀錄 | 辨識過的文字都存在 `history.txt`（只存在你的電腦） |

## 常見問題

- **安裝程式說「不是 Apple 晶片」或「需要 macOS 26 以上」**：這台 Mac 不符合需求，見上面「需要什麼」
- **跳出「要安裝命令列開發者工具嗎」的視窗**：語音輸入用不到，按「取消」就好
- **按 Fn 沒反應**：檢查「輸入監控」有沒有打開「語音輸入」
- **文字沒有貼上，只複製了**：「輔助使用」沒打開，打開後就會自動貼上
- **按 Fn 跳出表情符號或切換輸入法**：照上面「第一次打開」第 3 步把 🌐 鍵改成「不執行任何動作」
- **浮動條顯示「蘋果辨識沒辦法啟動」**：通常是第一次打開時沒網路，語言包沒下載成功。連上網路後按一下 Fn 就會重試
- **辨識不準**：通常是麥克風的問題，在選單「麥克風」換一支試試；常錯的英文詞用「自動更正」
- **麥克風卡住、程式閃退**：會自動重新啟動，浮動條會告訴你；等 1～2 秒再按一次 Fn 就好
- **出問題時**：資料夾裡的 `voice_type.log` 有執行紀錄

## 移除

1. 點浮動條，先取消「登入時自動啟動」，再按「結束語音輸入」
2. 把整個 `語音輸入` 資料夾丟到垃圾桶
3. 「系統設定 → 隱私權與安全性 → 輸入監控／輔助使用」裡把「語音輸入」刪掉
4. 安裝時自動下載的 uv 和 Python 在 `~/.local/bin/uv`、`~/.local/share/uv`、`~/.cache/uv`，其他程式沒在用的話也可以刪掉

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `安裝App.command` | 安裝：檢查需求、下載套件、產生 `語音輸入.app` |
| `語音輸入.app` | 安裝後才會出現，雙擊啟動 |
| `voice_type.py` | 主程式：快捷鍵、貼上、設定選單 |
| `engine.py` | 錄音與語音辨識 |
| `pill.py` | 桌面浮動條 |
| `relaunch.py` | 閃退時自動重新打開 |
| `app/` | 已經編譯好的蘋果辨識小幫手（`apple-speech`）、App 啟動程式（`voice-type-launcher`）和圖示，原始碼也在裡面 |
| `使用說明.html` | 有圖的安裝說明（跟網頁版一樣） |
| `config.json` | 設定（第一次改設定後才會出現） |
| `history.txt` | 辨識紀錄（只存在你的電腦） |
